# Reports & Walk Throughs
**Summary**

This repository contains a collection of walkthroughs and OSCP style reports. The purpose of creating this repo is to gain practice in writing documentation that is clear and easy for a reader to both follow and reproduce the steps contained therein.

Walk Throughs will be very short documents containing all the steps and just enough explanation if necessary of the procedures to complete a machine. Reports will be detailed, professionally written documents to prepare for the OSCP.
